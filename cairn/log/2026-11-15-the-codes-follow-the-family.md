# The codes follow the family

A command naming no calendar where none is the default fails coded `calendar-default-missing`, and the pimdir codes calendula relays are Himalaya's, lines K13 and K16 of the CLI alignment round. Capabilities **commands** and **backends** moved.

- **src/error.rs, src/account/context.rs, src/pimdir/backend.rs**: `calendar-default-missing`, ``No default calendar found, name one with `-k <CALENDAR-ID>` or set `calendar.default` ``, from the one resolver unified and pimdir commands share.

- **src/pimdir/backend.rs**: the staging refusals calendula words carry `unsupported`, the performer refusals `no-performer` and `ambiguous-performer`, and a capability read goes through the relay.
- **Evidence**: on the code before, tests/write.rs read `code: null` for a missing default calendar, the store failure test found no code for the new variants, and the online-meeting refusal read `null`.
