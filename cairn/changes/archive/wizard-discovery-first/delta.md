# Delta

## ADDED Requirements

The wizard capability is added wholesale by this change: input orientation, the typed-URL deviation, the bounded discovery, the per-service auth prompt, and the derived account name.

It also adds the test before printing, the print-or-save rule, the stop when nothing is discovered, the local auto-detection, and the rule that the wizard never serves a running command.
